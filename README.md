# Axzel Fajarillo — Architecture Portfolio

This folder is the finished, share-ready website.

## View it on your computer

Open `index.html` in any web browser.

## Edit it

Click **Edit portfolio** in the top-right corner to change your details and subject names. Click a subject to add or remove plates. These quick edits are saved only in the browser you use.

## Publish it online

Upload every file and folder in this folder to a static website host, such as GitHub Pages, Netlify, or Vercel. Keep the folder structure unchanged, especially the `graphics` folder.

Once the site is published, share the website address with anyone. To make changes visible to everyone, update the site files and publish them again.
